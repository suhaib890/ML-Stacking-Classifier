# ML Stacking Classifier

This project demonstrates Stacking Ensemble Learning using multiple machine learning models.

## Base Learners

- Decision Tree Classifier
- Support Vector Classifier (SVC)
- Logistic Regression

## Final Estimator

- Logistic Regression

## Dataset

Iris Dataset

## Cross Validation

5-Fold Cross Validation

## Result

Accuracy: 96.67%

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Seaborn
